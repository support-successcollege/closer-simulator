# CLOSER Simulator

סימולטור אימון מכירות בעברית (RTL). מתאמן בוחר שלב בתהליך המכירה, עונה על
שאלות תרחיש, ומקבל משוב מיידי עם הסבר והערת מאמן אחרי כל תשובה.

נבנה מאותו בסיס קוד של INFINIX Simulator — ראה [מה משותף ומה נפרד](#יחס-ל-infinix-simulator).

## התקנה והרצה מקומית

```bash
pnpm install
cp .env.example .env.local   # ערוך את סיסמת ההתקנה
pnpm dev                     # http://localhost:3000
```

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `pnpm dev` | שרת פיתוח עם HMR |
| `pnpm check` | בדיקת טיפוסים |
| `pnpm test` | בדיקות (Vitest) |
| `pnpm verify` | `check` + `test` — הרץ לפני push |
| `pnpm build:pages` | build סטטי ל-`dist/public` |
| `pnpm preview:pages` | תצוגה מקומית של ה-build |

## מאגר האימון

56 שאלות ב-7 קטגוריות, מסודרות **לפי שלב בתהליך המכירה** ולא לפי ענף —
כי המיומנות היא שנלמדת, והיא זהה בין נדל"ן לתוכנה:

| | קטגוריה | שאלות |
|---|---|---|
| 🤝 | פתיחה ובניית אמון | 8 |
| 🔍 | גילוי צורך ותשאול | 8 |
| 💡 | הצגת ערך | 8 |
| 🛡️ | טיפול בהתנגדויות | 8 |
| ⚖️ | מחיר ומשא ומתן | 8 |
| 🎯 | סגירה | 8 |
| 🔄 | שימור, חידוש והרחבה | 8 |

לכל שאלה ארבע אפשרויות, **הסבר** שמלמד למה התשובה נכונה, ו**הערת מאמן**
עם טיפ מעשי. מיקום התשובה הנכונה מאוזן — 14 שאלות בכל אחת מארבע
העמדות — כדי שלא ניתן יהיה לנחש לפי מיקום.

המאגר נמצא ב-`client/public/question_bank_infinitycloser.json`. אפשר
להחליף אותו דרך מסך הניהול בלי לגעת בקוד.

### מבנים נתמכים

```jsonc
{ "categories": { "שם הקטגוריה": { "icon": "🎯", "questions": [
    { "id": "q1", "question": "...", "options": ["א","ב","ג","ד"],
      "correctIndex": 0, "explanation": "...", "coachNote": "...",
      "difficulty": "medium", "status": "active" } ] } } }
```

שאלות עם `status` של `archived` או `draft` אינן מוגשות למתאמנים.
שאלות באותו מבחן לעולם אינן חוזרות — אם בקטגוריה יש פחות שאלות
מהמבוקש, המבחן קצר יותר והאשף מודיע מראש.

## אבטחה — לקרוא לפני העלייה לאוויר

ההתחברות היא **שער תצוגה, לא אבטחה**: היא רצה בדפדפן המשתמש וניתנת
לעקיפה. אל תאחסן מאחוריה מידע רגיש. הפרטים ב-[`docs/SECURITY.md`](docs/SECURITY.md).

מה שכן מוגן באמת: פרסום מאגר שאלות משותף דרך `/api/question-bank` נבדק
בצד השרת מול `ADMIN_UPLOAD_TOKEN` — בדיקה שהדפדפן לא יכול לעקוף.

## יחס ל-INFINIX Simulator

הפרויקט שוכפל מ-`support-successcollege/infinix-Simulator` ומשתף איתו את
כל התשתית: אימות, התמדה, מנוע החידון, מסך הניהול וה-API של המאגר
המשותף. מה שנפרד הוא התוכן והמיתוג.

⚠️ שני הפרויקטים אינם מסונכרנים. תיקון תשתיתי באחד — אבטחה, נגישות,
באג במנוע — צריך להיות מועבר ידנית לשני.
